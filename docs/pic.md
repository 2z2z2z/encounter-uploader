# Новый тип уровня - "Свалка картинками"

Весь функционал типа уровня стандартный, но есть особенности:
1. Нужно создать 2 поля (простые инпуты):
- `closedPic`
- `openPic`
2. Под них нужно создать 2 контрола (простые инпуты), соответственно:
- `closedPicNames`
- `openPicNames`
3. Для одной строки ответа нужно сделать добавление нескольких `closedPic` и `openPic` (такие же кнопки добавления/удаления и принцип как у вариантов ответов). Сделай эту функцию универсальной, без хардкода, чтобы настраивалась в конфиге (как опция для полей `closedPic` и `openPic`). Причем, если в рамках одного ответа добавить еще один `closedPic`, то автоматически добавится и `openPic`, добавление/удаление этих полей должно быть взаимосвязано. Получается, что у одного ответа может быть 1 или несколько `closedPic` и `openPic`. При этом, количество `closedPic` всегда равно количеству `openPic`. Пусть кнопка добавления/удаления будет у `closedPic`, а `openPic` будет просто зависимым полем
4. Для заливки задания по кнопке `uploadTask` будет генерироваться такой пейлоад:
- блок-враппер максимальной шириной 1080px, адаптивный
- в блоке-враппере квадратные блоки (с id="levelid_XX", где XX - это порядковый номер), содержание которых - поля `closedPic` максимальной шириной и высотой 120px. Их содержание: ссылка на картинку (тогда нужно ее вставлять с тегом <img> с параметрами размеров 120x120 px или ссылка с картинкой вида <a><img></a> - тогда делать ничего не нужно, оставить как есть)
- количество квадратных блоков соответствует количеству `closedPic` или `openPic` со всех табов (а не только с активного)
- квадратные блоки упорядочены по горизонтали
- при заливке задания, все квадратные блоки (со всех табов, не только с активного) должны быть перемешаны, чтобы их порядок был случайным, а не таким же как в таблице ответов. При этом, не нужно группировать по ответам, если у одного ответа несколько `closedPic` и `openPic` (из пункта 1). Для этого лучше создать какую-то универсальную мапилку, которая может быть использована также в других типах уровней. Эта мапилка должна быть доступна из интерфейса, чтобы пользователь видел какой будет выходной порядок при заливке и мог менять его вручную или "перерандомить"
5. При добавлении ответов, поле `openPic` должно быть предзаполнено блоком, в котором большой зеленый минималистичный svg-чекбокс 100x100 px
6. В предпросмотре как и у типа "Олимпийка" должно быть 2 вида: закрытый (с контентом `closedPic`) и открытый (с контентом `openPic`)
7. Для пейлоада бонусов в `hint` отправлять такой код (по аналогии с типом "Олимпийка"):
```<script type="text/javascript">document.getElementById("levelid_XX").innerHTML="{openPic}";</script>```
где в `levelid_XX` - `XX` - это порядковый номер, `{openPic}` - это контент поля `openPic` (из пункта 3)
